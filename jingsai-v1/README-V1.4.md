# 竞赛一体化管理平台 · 小程序 V1.4（版本说明）

> 在 V1.3 哈希防伪与报表中心之上，点亮**知识分享闭环**：知识广场（经验帖 / 获奖名单 / 模板库）、消息中心分组页签、报表评审绩效。
> 视觉延续「墨纸编辑部」设计语言；数据层继续云优先 + Storage 回落，纯前端零配置演示。

## 一、本版本功能（V1.4 做了什么）

| 模块 | 功能 |
| --- | --- |
| **知识广场（新页 · 第 11 页）** | 首页学生宫格「知识广场」从 V2.0 占位点亮为可进入。报纸副刊式三档栏目：**经验帖 / 获奖名单 / 模板库**，带计数页签切换 |
| **经验帖** | 6 篇往届选手实战帖（数模国赛节奏管理、大创痛点证据链、电设 21 天清单、挑战杯申报书、英语演讲开场、答辩 PPT 结构），每篇含 赛事赛道 / 作者头衔 / 阅读点赞 / 摘要；点开即**全文弹层**（正文分段 + 首行缩进 + 报纸完稿标记） |
| **获奖名单** | 按赛季分组的往届荣誉墙：奖次徽章（国一·朱砂 / 国二·靛蓝 / 省一·纸灰）+ 队伍 + 成员 + 指导教师，标注演示数据身份 |
| **模板库** | 4 份可直接用的文本模板（数模论文骨架 / 大创申报书九段 / 挑战杯申报要点 / 路演 PPT 1-10-1）：「✂ 复制模板要点」一键进剪贴板（沙盒导出闭环），弹窗回执字数 |
| **消息中心分组** | 来函页签 全部 / 审批 / 催办 / 公告（带总数计数，类型页签附未读红点），切签即过滤；仍遵守设置页通知偏好开关 |
| **报表 · 评审绩效** | 报表中心新增「评审绩效」小节：按审批人展示 已办件数 / 通过·驳回分色堆叠条 / 通过率；在办负荷（待审 N）单列徽章；无已办记录者如实显示「暂无已办 · 待审 N 件」 |
| **内容即数据** | 知识广场全部内容由 data.js 静态 seed 提供（只读、不占 Storage），接口命名与竞赛/报名集合一致，后续可无痛切云端 |

## 二、代码说明

### 数据层 `utils/data.js`（V1.4 新增/调整）
| API / 函数 | 说明 |
| --- | --- |
| `seedPlazaPosts()` | 6 篇经验帖 seed：`{ _id, comp, track, author, from, title, views, likes, date, brief, body[] }`，body 为段落数组（wxml 逐段渲染，规避换行符兼容问题） |
| `seedWinnerGroups()` | 3 组获奖名单 seed：`{ _id, season, comp, rows:[{ grade: gold|silver|bronze, prize, team, members, teacher }] }`，grade 驱动徽章配色 |
| `seedTemplates()` | 4 份模板 seed：`{ _id, name, tag, desc, copyText }`，copyText 为 300-600 字纯文本要点 |
| `getPlazaPosts() / getWinnerGroups() / getTemplates()` | 只读 getter（不进 K 存储键），返回上述 seed 的“当前实例”，为未来云端集合预留同形接口 |
| `reportStats()` | 返回值新增 `approverStats`：遍历全部报名节点的 `approver`（跳过 `—`/`待定`），按人聚合 `pass / reject / pending(在办) / done / rate`，按 `done+pending` 降序；`rate` 无已办时为 `null`（页面渲染 `—`） |

> 统计口径说明：`done` 只计已终结节点（pass/reject），`waiting` 计入 `pending` 而非已办——与审批中心「待我审批 / 我处理过的」口径一致，报表与队列互不打架。

### 知识广场 `pages/plaza/`（V1.4 新页）
- 三档页签 `tabs`（posts/winners/templates）由 `setTab` 切换，`counts[item.key]` 动态读总数；页头沿用自定义导航（`pl-back` ‹ 返回，fail 回落首页）。
- 经验帖全文弹层 `pl-mask > pl-modal`：`scroll-view` 限高 62vh 滚动，遮罩 `bindtap=closePost` + 内容区 `catchtap=noop` 阻断冒泡；正文段落 `pm-para` 首行缩进 2em。
- 模板复制走 `wx.setClipboardData` + `showModal` 回执（沙盒内文件不可下载，剪贴板是最短可用闭环）。
- `plaza.json` 自定义导航 + `app.json` 注册第 11 页；首页宫格第 4 格 `soon()` 替换为 `goPlaza()`（移除 off/soon 占位样式）。

### 消息中心 `pages/messages/`（V1.4 增量）
- 常量 `TABS`（all/approval/urge/notice）；`refresh()` 先按通知偏好过滤出 `visible`，再累计 `counts` 与 `unreadTab`（all 为未读总和），最后按 `data.tab` 过滤渲染——偏好关闭的类别直接不出现在列表与计数。
- 页签红点规则：仅类型签（审批/催办/公告）显示未读红点，`全部` 签不重复（顶部「N 封未读来函」已表达）。
- `setTab` 只写 `tab` 后复用 `refresh()`，读已读/单条跳转逻辑不变。

### 报表中心 `pages/reports/`（V1.4 增量）
- `refresh()` 消费 `s.approverStats` 构造 `perf`：条宽 `w` 按该人已办量 / 全员最大已办量归一（下限 6%），条内 `passW/rejectW` 为已办内部百分比分色（通过·绿 / 驳回·朱砂）；`rate` 为 `null` 时 `rateTxt='—'` 并渲染空态行「暂无已办 · 待审 N 件」。
- 版本号 V1.3.0 → V1.4.0（settings 同步）。

### 兼容性
V1.0—V1.3 的 Storage 结构与键全部不变：知识广场为只读内容源不占存储、不加新键；`reportStats()` 返回值向后兼容（新增字段不影响既有调用方）；消息中心 `data.tab` 为页面态，无持久化。重置路径不变：我的 → 重置演示数据。

## 三、下一版本迭代功能（V1.5）

- **服务端签名防伪**：节点哈希改由服务端私钥签名（HMAC/国密），客户端只验签不产签——关闭客户端哈希的演示级边界（自 V1.4 顺延，需后端）
- **云开发正式接入**：报名 / 消息 / 队伍 / 知识内容集合云端化、多端实时同步，替换 Storage 主路径（自 V1.4 顺延，需云环境）
- **订阅消息正式推送**：小程序后台申请模板 ID → `requestSubscribeMessage` 走真推送；审批通过 / 驳回 / 催办按事件下发服务通知（需真机 + 后台配置）
- **知识广场互动化**：帖子详情独立页、收藏 / 点赞 / 我要发帖（审核流）、获奖名单按年度筛选、模板附件化（docx/pdf 上传与下载）
- **报表增强**：XLSX 导出（sheetjs）、按赛项 / 日期范围筛选联动图表、单个审批人绩效下钻页
- **消息能力**：单条已读、批量删除、按报名单聚合时间线
