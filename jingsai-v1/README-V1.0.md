> 视觉方案：**墨纸编辑部**（纸 #F4EDDF · 墨 #1A1815 · 朱砂 #C8442A）
> 依据《竞赛一体化管理平台-反主流重设计原型.html》落地为可运行的小程序代码。

## 一、本版本功能（V1.0 做了什么）

V1.0 交付**学生赛道完整闭环**：登录 → 大厅浏览 → 详情 → 组队报名 → 多级审批 → 驳回重交 → 撤回/催办 → 档案柜回看。

| 页面 | 功能 |
| --- | --- |
| 登录 | 创刊号报头 + unDraw 插画 + 三种身份票根（V1.0 仅学生可用，教师 V1.1 / 管理员 V3.0 置灰标注） |
| 首页 | 报头日期期号（按周计算）、CSS 跑马灯快讯、Pexels 头版 Banner、功能宫格、报名进度卷宗（节点轨道 + 版本号） |
| 大厅 | 学科/创新创业双赛道切换、关键词搜索、筛选 chips（可报名/国家级/已截止）、竞赛卡（级别印章：A 朱砂 / B 靛蓝 / C 墨灰）、已截止 55% 透明 |
| 详情 | Pexels 照片蒙版 + 返回、时间轴（当前节点荧光黄）、组队要求卡、收藏（本地 js_favs）、重复报名拦截、底部固定报名栏 |
| 报名 | 公文纸版式 + 「受理专用章」、队名楷体输入、队员池点选（队长荧光标记 / 点头像移除）、指导教师卡片选择、附件上传（模拟）、提交后受理章弹窗 |
| 审批 | 学生侧「我发起的」：可展开全链路（✓/✕ 节点、驳回意见引用、超时条、催办/撤回/改完重交 v+1） |
| 我的 | 档案柜版式：卷宗式报名条目 + 迷你进度轨道、三格统计、证书空状态（unDraw 插画）、操作记录、重置演示数据、退出 |

### 审批链引擎（核心规则）
| 竞赛级别 | 审批链 |
| --- | --- |
| A 类（国家级） | 系统初审 → 指导教师 → 系级 → 院级 → 校级（5 级） |
| B 类（省部级） | 系统初审 → 指导教师 → 院级（3 级） |
| C 类（校级） | 系统初审 → 指导教师（2 级） |

- 系统初审 `auto: true`，提交即自动通过（表单完整性校验）
- 驳回后重交 → 版本号 +1，被驳回节点重置为「待审」，其余节点结果保留
- 全流程通过 → 朱砂「审批通过章」

## 二、代码说明

```
jingsai-v1/
├── app.js            # statusBarHeight(sbh) 计算、wx.cloud.init try/catch 兜底、login(role)/logout
├── app.json          # 7 页 + 纯文字 tabBar（首页/大厅/审批/我的），navigationStyle custom
├── app.wxss          # 设计系统：色板/纸张噪点/硬阴影卡片/印章/票据/条形码；--serif/--hand/--mono 字族变量
├── styles/illus.wxss # unDraw 插画（换色 + Base64），由 build_illus.py 生成
├── utils/data.js     # 数据层（核心）
└── pages/            # login/home/hall/detail/form/approval/profile 四件套
```

### 关键实现
- **零配置演示**：`utils/data.js` 云开发优先 + `wx.setStorageSync` 回落，两套数据源结构一致，未开通云开发可跑通全链路。
- **SVG 内嵌**：微信 `<image>` 不支持 SVG → WXSS `background-image: url(data:image/svg+xml;base64,...)`。
- **自定义导航**：`navigationStyle: custom` + `globalData.sbh` 传给页面做 `padding-top`。
- **CSS 手绘组件**：印章（148rpx 朱砂圆章 rotate -11deg）、条形码（渐变条纹）、票根、驳回引用条。
- **数据 API**：`getCompetitions/getTeachers/getMyRegistrations/submitRegistration/resubmit/withdraw/act/urge/log/getLogs/resetDemo`。

- 3 位指导教师（陈默 / 林一舟 / 许知远）
- 3 条报名单：夜航西飞 v2 停系级（演示改完重交）、白鹭队 v1 审批中、无线充球队已驳回

JSON 合法性 / wxml 事件函数定义 / `{{}}` 变量可溯源 / `node --check` JS 语法 / CSS 变量差集比对。
