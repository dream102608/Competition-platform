# 🚀 部署指南：从零到「扫码就能用」（V2.0）

> 写给零基础的你。照着做，每一步都说清楚了点哪里。
> 全程大约 **1~2 小时**（微信审核 1~7 天不算在内）。

---

## 总览：5 大步

```
① 注册你自己的小程序账号（拿到 AppID）     ← 10 分钟，免费
② 微信开发者工具里导入这份代码            ← 5 分钟
③ 开通「云开发」，创建 19 个集合，导入种子   ← 20 分钟
④ 部署云函数，点一遍全流程测试            ← 15 分钟
⑤ 上传 → 提交审核 → 发布 → 拿到正式二维码  ← 审核 1~7 天
```

---

## 第 ① 步：注册小程序账号

1. 打开 **https://mp.weixin.qq.com** →「立即注册」→「小程序」
2. 填邮箱（没注册过公众号平台的）→ 激活 → 主体选「个人」（免费）
3. 按提示实名（微信扫码确认）
4. 登录后左侧「开发管理 → 开发设置」复制 **AppID**

> 💡 也可以先用「测试号」开发（developers.weixin.qq.com 里申请），功能一样能测，只是不能正式发布。

## 第 ② 步：导入代码

1. 打开微信开发者工具 → 扫码登录 →「导入项目」
2. 目录选择 `jingsai-v1`（本文件所在文件夹）
3. 打开 `project.config.json`，把 `appid` 换成你的 AppID
4. 点「编译」，能看到登录页即成功（此时是本地演示模式）

## 第 ③ 步：开通云开发 + 建数据库

1. 开发者工具顶部点「**云开发**」→ 开通 → 环境名随意（如 `jingsai`）→ 选「按量付费」（免费额度内不扣钱）
2. 进入云开发控制台 →「数据库」→ 逐个新建集合，共 **19 个**，名字一字不差：

**A 组：公开内容（8 个，建完要导入种子数据）**

| 集合名 | 存什么 | 对应种子文件 |
|---|---|---|
| `competitions` | 竞赛列表（学生+教师双赛道） | `seed/competitions.json` |
| `teachers` | 指导教师/辅导员 | `seed/teachers.json` |
| `news` | 新闻动态 | `seed/news.json` |
| `trainings` | 培训课程 | `seed/trainings.json` |
| `learning_knowledge` | 知识广场帖子 | `seed/learning_knowledge.json` |
| `knowledge_comments` | 帖子评论 | `seed/knowledge_comments.json` |
| `point_exchange_products` | 积分商城商品 | `seed/point_exchange_products.json` |
| `organizations` | 学院/专业 | `seed/organizations.json` |

权限：这 8 个集合都设为「**所有用户可读，仅管理端可写**」。
导入：点进集合 →「导入」→ 选对应的 `seed/*.json` 文件 → 确定。

**B 组：业务数据（11 个，建空集合即可，程序自动写入）**

| 集合名 | 存什么 |
|---|---|
| `users` | 用户档案与角色 |
| `registrations` | 竞赛报名单（含审批链） |
| `leave_requests` | 请假单 |
| `training_signups` | 培训报名单 |
| `expenses` | 经费申请单 |
| `checkin_records` | 签到打卡记录 |
| `points_accounts` | 积分账户 |
| `point_exchange_records` | 积分兑换记录 |
| `teams` | 队伍 |
| `schedules` | 学生课表 |
| `operation_logs` | 操作日志 |

权限：这 11 个集合都设为「**仅管理端可读写**」（安全：只能由云函数经手）。

## 第 ④ 步：部署云函数 + 测试

1. 文件树里右键 `cloudfunctions/api` →「**上传并部署：云端安装依赖**」
2. 点「编译」，完整点一遍：
   - 登录 → 首页看数据概览/新闻 → 竞赛大厅双赛道切换 → 详情页 → 提交报名
   - 请假页发起请假 → 知识广场发帖 → 课表页添加课程 → 签到打卡
3. 去云控制台 `registrations` 集合能看到刚提交的记录 = 成功 ✅

**体验审批**：云控制台 → `users` 集合 → 找到你的记录 → 把 `role` 改成 `teacher`（或 `dept`/`dean`/`admin`）→ 重新编译 → 审批中心就出现待办了。改成 `admin` 可使用「我的 → 系统管理」。

## 第 ⑤ 步：发布

1. 开发者工具右上角「上传」→ 填版本号 1.0.0
2. mp.weixin.qq.com →「版本管理」→「提交审核」→ 填类目（工具/教育）
3. 审核通过后点「发布」→ 下载正式小程序码 🎉

## 常见问题

| 问题 | 解决办法 |
|---|---|
| 页面显示假数据 | 检查：云开发开通了吗？19 个集合建了吗？云函数部署了吗？competitions 导入了吗？ |
| 报错 `collection not exists` | 集合名打错了，对照第③步清单检查 |
| 点审批提示「不归你审批」 | 正常！你的角色和当前审批节点不匹配，去 users 集合改 role 体验 |
| 查空闲学生没结果 | 先用学生身份在「我的课表」里添加几门课再查 |
| 想改竞赛/商品/新闻 | 不用改代码，云控制台直接改对应集合的数据 |

## 技术架构

```
用户手机微信
    │
    ▼
小程序前端（16 个页面）
    │
    ├── 直读公开集合（8 个：竞赛/教师/新闻/培训/知识点/评论/商品/组织）
    │
    └── 云函数 api（唯一后端入口）
          ├── 登录/资料、报名/请假/经费/培训/新闻 的提交
          ├── 通用审批引擎：通过/驳回(≥10字)/重报(v+1)/撤回/催办×3上报/手签字
          ├── 签到积分、商城兑换（库存+积分校验）
          ├── 知识互动（点赞/评论/置顶/精选）
          ├── 队伍管理（创建/申请/审批/副队长/日志/资料/讨论）
          ├── 课表保存 + 空闲学生计算（12 小节精确匹配）
          └── 统计聚合 + 管理员操作（角色分配/禁用/商品）
```

**角色分配说明**：12 种角色中，学生/教师/辅导员注册即得；队长创建队伍自动成为；其余角色（学赛负责人/教学秘书/教研室主任/副院长/院长/评审专家/管理员）由管理员在「系统管理 → 用户管理」里分配（第一个管理员账号请在云控制台 users 集合手动把 role 改成 admin）。

## V2.1 新增功能部署说明（Excel 导出 / 经费自动归档 / 新闻定时发布 / 大屏）

① **部署云函数时必须选「上传并部署：云端安装依赖」**——这样 exceljs 才会装上，Excel 功能才可用。
   （微信开发者工具 → cloudfunctions/api 右键 → 上传并部署：云端安装依赖）

② **上传定时触发器**（新闻定时发布用）：cloudfunctions/api 右键 →「上传触发器」。
   上传后每 5 分钟自动检查一次，到点且已审核通过的新闻会自动放出。

③ **经费自动归档**：无需任何操作。经费申请终审通过后，系统自动追加进
   云存储 `archives/经费归档_年-月.xlsx`（每月一个文件，云控制台 → 存储 可下载）。

④ **真 Excel 导出入口**：
   - 统计分析页（管理员/院长/副院长/教学秘书可见）→「报名名单.xlsx」「经费台账.xlsx」
   - 课表页空闲学生查询结果 →「导出空闲名单（Excel）」
   导出的文件会在小程序里直接打开，可转发/保存。

⑤ **可视化大屏**：双击打开 `dashboard/index.html`（在活动室电脑/电视上全屏即可）。
   默认显示演示数据；接入真实数据的方法写在该文件顶部注释里
   （填云环境 ID + 开启匿名登录 + 引入云开发 Web SDK）。
