# 竞赛一体化管理平台 · 小程序

> 视觉方案：**墨纸编辑部**（纸 #F4EDDF · 墨 #1A1815 · 朱砂 #C8442A）
> 一站式竞赛管理：学生报名组队、多级审批、教师签批、消息协同、知识分享。

## 快速开始

1. 打开 **微信开发者工具** → 导入项目 → 目录 `D:\Jingsai\jingsai-v1`
2. AppID 用「测试号」（`project.config.json` 已填 `touristappid`）或换成自己的
3. **不使用云服务** 即可完整体验：数据层云优先 + Storage 回落，零配置跑通全流程
4. 演示流程建议：
   - 学生票根：大厅报名 → 审批页「我发起的」→ 队伍管理 / 附件预览 / 催办 / 改完重交 / ⌑ 防伪校验 → 知识广场读帖·点赞收藏·**发帖走审核**·模板复制
   - 教师票根：审批页「待我审批」处理白鹭队 → ✎ 签名通过盖章 / 模板驳回 → 统计报表看聚合图表、**赛项筛选联动、绩效下钻**与双维导出
   - 评审票根：系级王建国登录 → 待办 1 件（夜航西飞 v2）→ 手写签名通过 → 报表下钻自己的逐单明细 / 导出 CSV → 学生端防伪校验「卷宗完整」
   - 消息中心：四档页签过滤 → **长按单条**（已读/查看/删除）→ **整 理**多选批量删除 → 夜航西飞两条动态聚成**卷宗时间线**
   - 学生可重置演示数据后对比（我的 → 重置演示数据）

## 设计系统（app.wxss）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--paper/-2/-3/-4` | #F4EDDF → #DCD2BC | 纸面层次 |
| `--ink/-soft/-fade` | #1A1815 / #4A443A / #8A8172 | 文字三级 |
| `--verm/-deep` | #C8442A / #A03521 | **唯一强调色**：印章、驳回、当前节点 |
| `--marker` | #F5D547 | 荧光笔：选中、队长、我经手的节点 |
| `--ind` / `--green` | #3D5A80 / #3E6B4F | B 类赛事 / 通过态 |
| `--serif/--hand/--mono` | 宋体 / 楷体 / 等宽 | 报头 / 手写批注 / 编号 |

标志组件全部 CSS 手绘：`.card` 硬阴影、`.seal` 朱砂圆章、`.pill` 票据胶囊、`.barcode` 条纹、`.rej-note` 驳回引用。
