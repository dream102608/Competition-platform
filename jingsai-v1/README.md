## 一、如何运行

<<<<<<< Updated upstream
1. 打开 **微信开发者工具** → 导入项目
2. 目录选择 `D:\Jingsai\jingsai-v1`
3. AppID 选择「测试号」（`project.config.json` 中已填 `touristappid`）或换成你自己的 AppID

## 快速开始

1. 打开 **微信开发者工具** → 导入项目 → 目录 `D:\Jingsai\jingsai-v1`
2. AppID 用「测试号」（`project.config.json` 已填 `touristappid`）或换成自己的
3. **不使用云服务** 即可完整体验：数据层云优先 + Storage 回落，零配置跑通全流程
4. 演示流程建议：
   - 学生票根：大厅报名 → 审批页「我发起的」→ 队伍管理 / 附件预览 / 催办 / 改完重交 / ⌑ 防伪校验 → 首页宫格进「知识广场」读帖·看榜·复制模板

## 三、设计系统（app.wxss）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--paper` / `--paper-2/3/4` | #F4EDDF → #DCD2BC | 纸面层次 |
| `--ink` / `--ink-soft` / `--ink-fade` | #1A1815 / #4A443A / #8A8172 | 文字三级 |
| `--verm` / `--verm-deep` | #C8442A / #A03521 | **唯一强调色**：印章、驳回、当前节点 |
| `--marker` | #F5D547 | 荧光笔：选中、队长标记、当前审批节点 |
| `--ind` / `--green` | #3D5A80 / #3E6B4F | B 类赛事、通过态 |
| `--serif` / `--hand` / `--mono` | 宋体 / 楷体 / 等宽 | 报头 / 手写批注 / 编号 |

**标志性组件**（全部 CSS 手绘，无图片依赖）：

- `.card` — 2~3rpx 墨色描边 + `8rpx 0` **无模糊硬阴影**（反 SaaS 柔光）
- `.seal` — 148rpx 朱砂圆章，`rotate(-11deg)`，模拟手盖歪章
- `.pill.st-run / .st-rej / .st-ok` — 票据式状态胶囊
- `.barcode` — 渐变条纹伪条形码
- `.rej-note` — 6rpx 朱砂左边框 + 楷体引用，驳回意见
- `.illus-*` — unDraw 插画（换色后 Base64 内嵌，微信小程序 `<image>` 不支持 SVG，故走 `background-image`）

## 四、V1.0 业务边界

**做**：学生赛道完整闭环 —— 浏览 → 详情 → 组队报名 → 多级审批 → 驳回重交 → 撤回/催办 → 档案柜回看。

**不做**（后续版本）：知识广场、教师端工作台、管理员端后台、真实文件上传、消息推送。

### 审批链引擎（`utils/data.js · chainFor`）

| 竞赛级别 | 审批链 |
| --- | --- |
| A 类（国家级） | 系统初审 → 指导教师 → 系级 → 院级 → 校级（5 级） |
| B 类（省部级） | 系统初审 → 指导教师 → 院级（3 级） |
| C 类（校级） | 系统初审 → 指导教师（2 级） |

- 系统初审 `auto: true`，提交即通过（表单完整性校验）
- 驳回后重交 → 版本号 +1，被驳回节点重置为「待审」，其余节点结果保留
- 全流程通过 → 出现朱砂「通过」终章印章

## 六、页面交互要点

| 页面 | 关键交互 |
| --- | --- |
| 登录 | 三种身份票根，V1.0 仅学生票根可用（教师/管理员置灰标注版本） |
| 首页 | 期号按周计算；走马灯通知；进度卷宗含节点轨道 + 版本号 |
| 大厅 | 双赛道切换、关键词搜索（标题/编号/主办方）、筛选 chips、已截止卡片 55% 透明 |
| 详情 | 收藏（本地 `js_favs`）、重复报名拦截弹窗、底部固定报名栏 |
| 报名 | 队名楷体输入、队员池点选（队长带荧光标记，点头像移除）、指导教师卡片选择、附件上传模拟、提交后「受理专用章」弹窗 |
| 审批 | 待我审批（系级视角）：4 条模板驳回理由 / 手写签名区 / 盖章确认；我发起的：可展开全链路、超时条、催办/撤回/重交 |
| 我的 | 档案柜：卷宗式报名条目 + 迷你进度条、证书空状态、操作记录、重置数据、退出 |
