# 竞赛一体化管理平台 · 小程序 V3.2

> 版本主题：**移动端参考图重排** —— 在「墨纸编辑部」设计语言之上，参考旅游类 App 的版式节奏（顶部地址条 → 胶囊搜索 → 大轮播 → 圆图标宫格 → 彩色 banner → 列表），对全部 18 个页面做移动端适配与栏目分区重排。
>
> 设计语言不变：纸 `#F4EDDF` / 墨 `#1A1815` / 朱砂 `#C8442A` / 荧光 `#F5D547`，宋体报头 + 楷体批注 + 等宽编号，印章 / 条码 / 票根 / 硬投影等标志性元素全部保留。

## 一、做了什么（本版完成项）

### 1. 导航与配色微调（app.json）

| 项 | 旧 | 新 |
| --- | --- | --- |
| 窗口背景 | `#EDE4CE` | `#F4EDDF`（与全局纸面一致） |
| tabBar 底色 | `#F4EDDF` | `#FBF7EC`（奶白，与卡片同色） |

### 2. 设计系统扩充（app.wxss · V3.2 区块）

新增一套**外层结构**通用类，与既有水墨元素（硬边、硬投影、印章）做「加法」而非替换：

- `.addr-bar / .addr-pick` — 顶部地址选择胶囊（学院 + 专业）
- `.search-pill` — 胶囊搜索栏（圆角输入 + 朱砂搜索钮）
- `.banner-sw / .banner-slide` — 大轮播 Banner（圆角 + 编号角标）
- `.icon-grid / .g5` — 圆图标宫格（2 行 × 5 列，圆形彩色徽标）
- `.banner-c`（ink / cream / green / blue / warm）— 彩色特色 Banner
- `.info-card / .card-soft` — 大圆角信息卡
- `.safe / .gap / .gap-lg` — 安全边距与呼吸留白
- `.chip / .chips` — 横向筛选胶囊
- `.row` — 通用列表行（编号 + 正文 + 操作）
- `.mask / .sheet / .sh-t / .sh-ops / .sh-btn` — **弹窗统一**（宽度固定 640rpx、`max-width: calc(100vw - 60rpx)`、大圆角、`max-height: 86vh` 内滚动）
- `@media (max-width: 320px)` — 窄屏防溢出（关键元素缩放 + 字号下调）

## 二、代码解析

### 核心思路：在外层做「呼吸感」，内层保留「墨纸魂」

```
V3.2 改动层级
─────────────────────────────
外层结构（新，大圆角）    .addr-bar / .search-pill / .banner-sw
                          .icon-grid / .banner-c / .info-card
─────────────────────────────
中层容器（复用）          .card 硬边硬投影 被大圆角容器承接
─────────────────────────────
底层原子（不动）          .seal 印章 / .barcode 条码 / .pill 胶囊
                          .rej-note 批注 / .medal 奖牌 / .tape 胶带
```

关键实现细节：

1. **胶囊搜索栏 `.search-pill`** — `height: 76rpx` + `border-radius: 999rpx`，输入区与搜索钮同高，搜索钮朱砂底色对仗纸面，符合「朱砂点睛」的语言。
2. **圆图标宫格 `.icon-grid`** — 用 `flex-wrap` + `.g5 { width: 20% }` 实现 2 行 × 5 列，圆形徽标 `.badge` 靠 `border-radius: 50%` + 硬投影做出「盖章」感；徽标底色由 JS 传入不同色，替代原来单调的文字宫格。
3. **彩色 Banner `.banner-c`** — 参考图「私人定制旅行」绿 Banner，但把配色约束在墨纸色板延伸色（墨黑 / 纸白 / 松绿 / 靛蓝 / 朱砂），文字仍用宋体报头，不破坏整体气质。
4. **弹窗统一 `.sheet`** — 原各页各自写 `620/660/680/690rpx` 宽度，现收口为单一定义，`max-width: calc(100vw - 60rpx)` 保证任意机型左右各留 30rpx，杜绝溢出。
5. **窄屏兜底** — `@media (max-width: 320px)` 对易溢出的元素做 `transform: scale(.92)` 缩放，仅作保险，正常机型不触发。
