设计宣言

Manifesto

我们反对的

  • 圆角大卡片 + 浅灰背景 + 蓝紫渐变按钮的「AI 三件套」
  • 什么都发光：阴影、描边、玻璃拟态，一屏十种特效
  • 黑白灰里点一个亮蓝就敢叫「品牌色」
  • 图标独角兽：一个界面混用五种图标风格
  • 没有触感：摸上去像玻璃，不像纸

我们坚持的

  • 一套墨色走天下：纸、墨、朱砂、荧光笔，四种材料说完所有事
  • 2px 油墨边框 + 硬投影——像盖章盖出来的，不是浮在空中的
  • 衬线大字做标题，像报纸头版一样有版面秩序
  • 票据、印章、胶带、条形码：把「办事」的仪式感做进界面
  • 手写批注留给关键提示——机器说人话，人才愿意读

小程序落地要点

Implementation Notes 
/* app.wxss — 墨纸版设计令牌 */
page {
  --paper: #F4EDDF;   /* 页面底 */
  --ink:   #1A1815;   /* 主墨 */
  --verm:  #C8442A;   /* 朱砂强调 */
  --marker: #F5D547;   /* 选中态 */
  --serif: "Noto Serif SC";
  --hand:  "Zhi Mang Xing";
}
.card {
  background: #FBF7EC;
  border: 2rpx solid var(--ink);
  box-shadow: 6rpx 6rpx 0 var(--ink);
}
  • 印章效果：CSS 圆形边框 + rotate(-11deg) + mix-blend-mode: multiply；小程序用 view 覆盖层实现，驳回理由左边线同款。签名板用 canvas 2d，笔迹粗细跟随速度。
  • 纸纹颗粒：feTurbulence SVG 转 base64 铺 5% 透明度全局伪元素，体积 2KB，不增加请求数。
  • 字体策略：衬线/手写字体包大，小程序侧先走系统兜底（SimSun / KaiTi），仅标题字号按需加载 woff2 子集（<80KB）。
  • 图片降饱和：Pexels/Picsum 统一 CSS filter: saturate(.8)——同一滤镜规则保证异源图片色调统一，这是「不像 AI 拼贴」的关键。
  • 图标内联：Tabler SVG 全部内联 wxml，色阶只留墨/朱砂/纸三份，杜绝运行时图标请求。
