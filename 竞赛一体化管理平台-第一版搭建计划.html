竞赛一体化管理平台 · 第一版（V1.0）搭建计划

依据《WorkBuddy 搭建小程序教程》的 MVP 方法论，对《竞赛一体化管理平台》需求文档进行第一版裁剪与排期

版本：V1.0（MVP）形态：微信小程序（云开发）日期：2026-09-01 团队：产品 / 开发 / 测试 / 运维（学生团队）工具：WorkBuddy + 微信开发者工具

1项目定位与一句话定义

教程第一课：先把产品压缩成一句话，再开始动手。

一句话定义：这是一个面向二级学院师生、覆盖「发布 → 报名 → 多级审批 → 归档」主线的学生竞赛管理小程序，第一版先让学生竞赛赛道跑通全流程。
  • 给谁用：学院本科生/专科生（报名）、教师与辅导员（一级审批）、学赛负责人/教研室主任/副院长/院长（逐级审批）、管理员（运维）。
  • 解决什么痛点：纸质/Excel 报名审批不透明、进度不可查、驳回后反复跑腿、数据无法沉淀。
  • 核心场景：按专业/教研室维度查看数据，未来可扩展至全校。
  • V1.0 成功标准（验收口径）：1 名学生可完成「注册 → 浏览竞赛 → 报名 → 被 5 级审批 → 看到报名成功」的完整闭环，全程线上可查。

8上线准备清单（过审材料）

  • ☐ 用户协议 + 隐私政策：网上模板改名称，放「设置」页可达（教程盲区三）。
  • ☐ 功能截图 ≥ 4 张：竞赛大厅、报名表单、审批中心、我的报名。
  • ☐ 服务类目：选择「教育 > 院校教务」或学院相应类目，避免驳回。
  • ☐ 自检清单：首页加载 < 3 秒；有「联系我们/反馈」入口；所有按钮点击有反馈（loading/成功/失败提示）。
  • ☐ 数据合规：涉及姓名/学号/手机号收集，隐私政策中如实声明用途。
  • ☐ GitHub 仓库 + README：项目介绍、运行方式、技术栈、分工（面试资产）。
